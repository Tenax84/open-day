# ISO 9660 disc images (game CD)

An image of the game CD can serve as the source of the game files
(`engine/formats/iso9660.*`, `engine/data/game_source.*`). This is the
standard CD file system (ECMA-119) with the Joliet extension, not a format
of the original game. Checked against images made by the Windows IMAPI2
image writer (ISO 9660 only, and ISO 9660 + Joliet).

## Sectors

The file system uses 2048-byte logical blocks. Image files come in two
sector layouts, detected by where the volume descriptor magic `CD001` of
block 16 is:

| Layout | Sector size | User data at |
|---|---|---|
| `.iso` | 2048 | 0 |
| raw mode 1 (`.bin` of a `.bin`/`.cue` pair) | 2352 | 16 (after sync and header) |
| raw mode 2 form 1 (XA) | 2352 | 24 (after sync, header and subheader) |

Block *n* is the 2048 user bytes of sector *n*.

## Volume descriptors

From block 16, one descriptor per block: byte 0 type, bytes 1–5 `CD001`,
byte 6 version. Type 255 ends the list.

- Type 1, **primary**: volume name at 40 (32 characters, space-padded);
  root directory record at 156 (34 bytes).
- Type 2, **supplementary**, is **Joliet** when bytes 88–90 are `%/@`,
  `%/C` or `%/E` (UCS-2 levels 1–3). Same fields; names are UCS-2
  big-endian.

The Joliet tree is used when present (long, mixed-case names); otherwise
the primary tree.

## Directory records

A directory is a run of blocks holding records; a record never crosses a
block boundary (a length byte of 0 means: continue at the next block).

| Offset | Size | Field |
|---|---|---|
| 0 | 1 | record length |
| 2 | 8 | first block of the extent (little-endian u32, then big-endian) |
| 10 | 8 | data length in bytes (both byte orders) |
| 25 | 1 | flags: bit 1 directory, bit 7 more extents follow for this file |
| 32 | 1 | name length *n* |
| 33 | *n* | name |

The first two records of a directory are itself (name byte 00) and its
parent (01). File names end with a version (`;1`), which is dropped, and an
extension-less primary name ends with `.`, also dropped. A file larger than
an extent has several consecutive records with the same name; all but the
last have flag bit 7; its data is the extents in order.

## Finding the game

The game folder on the disc is the shallowest folder that contains both
`GLOBALS/GLOBAL.MDB` and `INTERF/PAL.BMP` (names compared without regard
to case); everything below it is copied. If that folder has no
`EXE/LIBDAY.EXE`, a `LIBDAY.EXE` and `LIBDAY*.DLL` found elsewhere on the
disc are copied into `EXE/`. A disc without such a folder (for example
one holding only a compressed setup) is refused.

*Unverified:* the layout of the original 1998 CD has not been examined; the
rules above accept the game folders at the root or in any subfolder.
