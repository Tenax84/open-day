# Clean-room documentation

This directory holds **descriptions written in our own words** of the data
formats (`formats/`) and game mechanics (`mechanics/`) of the original game.

Rules:

- No decompiler output, pseudocode or assembly — not even paraphrased line by line.
- No excerpts or dumps of original game data.
- Describe fields, offsets, algorithms, constants and observed behavior.
- Mark unverified assumptions explicitly (e.g. with "?" or an *Unverified* note).

The engine is implemented **only** from these documents.
