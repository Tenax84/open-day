# Code of conduct

OpenDay is a small hobby project. Everyone who takes part (in issues, pull
requests, discussions or anywhere else in the project) is expected to:

- be respectful and patient, especially with newcomers and with people whose
  first language is not English;
- criticize ideas and code, not people;
- assume good intent, and ask before concluding otherwise;
- keep discussions on topic.

Not acceptable: harassment, insults, discrimination, sexual or violent
content aimed at others, publishing someone's private information, and
sustained disruption.

Also not acceptable in this project: posting or linking original game files,
pirated copies of the game, or decompiled code of the original program (see
[CONTRIBUTING.md](CONTRIBUTING.md)).

The maintainer may edit or remove contributions and comments that break these
rules, and may temporarily or permanently block people from the project.
Report problems privately to the maintainer through
[GitHub](https://github.com/Tenax84) or, if it concerns security, as
described in [SECURITY.md](SECURITY.md).
